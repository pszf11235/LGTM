# LGTM

AI agents let you open five PRs in an hour. Now you have to review them.

LGTM watches your repositories, reviews new pull requests with the AI CLI you
already have installed, and leaves the findings on your disk. Nothing reaches
GitHub until you say so, and when it does it arrives as a draft review you can
edit comment by comment before submitting.
